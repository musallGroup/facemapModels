LabelForge v0.0.1

Minimaler klickbarer Prototyp.

Enthalten:
- Label Workspace
- Training Workspace
- Help-Button
- Create Base Model
- Refine Existing Model
- Specialize Base Model
- einfache Dummy-Seiten, damit der Workflow klickbar ist

Start:
1. Öffne Anaconda Prompt.
2. Aktiviere dein Python-Environment.
3. Installiere PySide6:
   pip install PySide6
4. Wechsle in diesen Ordner.
5. Starte:
   python app.py
